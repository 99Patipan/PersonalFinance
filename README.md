# สมุดรายรับ-รายจ่าย (PersonalFinance)

แอป Android (Kotlin + Jetpack Compose + Material 3 + DataStore) เก็บข้อมูลบน **Supabase** (Postgres + Storage) ของคุณเอง ต้องล็อกอิน และต้องใช้อินเทอร์เน็ตเพื่อดู/บันทึกข้อมูล ไม่มีโฆษณา

## วิธีที่ 1: Build APK ด้วย GitHub Actions (ไม่ต้องลง Android Studio)
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github` ที่เป็นโฟลเดอร์ซ่อน) ที่ branch `main`
3. ไปที่แท็บ **Actions** > **Build APK** (รันเองเมื่อ push หรือกด **Run workflow**)
4. เมื่อเสร็จ เปิดการรันนั้น เลื่อนลงไปที่ **Artifacts** แล้วดาวน์โหลด `PersonalFinance-apk` (ข้างในคือ `PersonalFinance.apk`)
5. ถ้า Build ไม่ผ่าน ดู Log ในขั้นตอนที่ขึ้นสีแดง และ Artifact ชื่อ `build-logs`

## วิธีที่ 2: Build ใน Android Studio
เปิดโฟลเดอร์นี้ด้วย Android Studio (Koala ขึ้นไป, JDK 17) รอ Gradle Sync แล้วกด Run หรือ Build > Build APK(s)
ไฟล์จะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

> หมายเหตุ: `gradle-wrapper.jar` (ไฟล์ไบนารี) ไม่ได้รวมมาด้วย Workflow ใช้ Gradle 8.9 ผ่าน `gradle/actions/setup-gradle` จึงไม่ต้องใช้ไฟล์นี้
> ถ้าต้องการใช้ `./gradlew` ให้รัน `gradle wrapper --gradle-version 8.9` หนึ่งครั้ง (Android Studio สร้างให้อัตโนมัติ)

## ติดตั้งบนมือถือ
คัดลอก APK ไปที่เครื่อง เปิดไฟล์ แล้วอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" (Android 8.0 ขึ้นไป)

## ฟีเจอร์
- Dashboard: ยอดรวม กระเป๋า สรุปเดือน ปฏิทินรายวัน ธุรกรรมล่าสุด กราฟ สัดส่วนหมวด งบประมาณ บันทึกของฉัน
- เพิ่ม/แก้ไข/ลบ (มีหน้าต่างยืนยัน)/ดูรายละเอียด/ค้นหา/กรอง รายการ, ทศนิยม 2 ตำแหน่ง, แนบรูปใบเสร็จ
- หลายกระเป๋าเงิน โอนระหว่างกระเป๋า (ไม่นับเป็นรายรับ/รายจ่ายรวม) ยอดคงเหลือคำนวณจากรายการจริงเสมอ
- หมวดหมู่เริ่มต้น เพิ่ม/แก้ไข/ลบได้
- รายงานรายเดือน/รายปี เปรียบเทียบเดือนก่อน ค่าเฉลี่ยต่อวัน หมวดที่ใช้มากสุด
- งบประมาณรายเดือนตามหมวด พร้อมแจ้งเตือนเมื่อใกล้เกิน (ตั้งได้ 70/80/90%)
- ส่งออก CSV, สำรอง/กู้คืน JSON (รวมรูปใบเสร็จ) ผ่าน Storage Access Framework

## การเชื่อมต่อ Supabase
- โปรเจกต์: `personal-finance` (ภูมิภาค Singapore) ค่า URL และ publishable key อยู่ใน `data/SupabaseConfig.kt`
  (publishable key เปิดเผยในแอปได้ ความปลอดภัยมาจากการล็อกอิน + Row Level Security)
  ถ้าเข้าสู่ระบบไม่ได้ด้วยคีย์นี้ ให้เปลี่ยน `API_KEY` เป็น legacy anon key (Settings > API Keys)
- โครงสร้างฐานข้อมูลและกฎความปลอดภัยอยู่ใน `supabase/schema.sql` (ใช้สร้างใหม่ได้ถ้าย้ายโปรเจกต์)
- ตาราง: `wallets`, `categories`, `transactions`, `budgets` ทุกแถวมี `user_id` และเปิด RLS ให้เห็น/แก้ได้เฉพาะเจ้าของ
- รูปใบเสร็จเก็บใน Storage bucket `receipts` (ส่วนตัว) path แบบ `<userId>/<uuid>.jpg` แอปย่อรูปก่อนอัปโหลด (ด้านยาว 1280px)
- การเข้าสู่ระบบ: อีเมล + รหัสผ่านของบัญชีที่สร้างไว้ใน Authentication > Users แอปจำการเข้าสู่ระบบไว้
- ข้อควรรู้: แผนฟรีของ Supabase จะพักโปรเจกต์ถ้าไม่มีการใช้งานนาน 1 สัปดาห์ (ข้อมูลไม่หาย กดกู้คืนที่ Dashboard ได้)
  แนะนำให้สำรอง JSON เป็นระยะ

## ข้อมูลเริ่มต้น
ข้อมูลเริ่มต้นนำเข้าจากไฟล์สำรองเดิมแล้ว (1 กระเป๋า, 21 หมวดหมู่, 21 รายการ)
บัญชีใหม่ที่ไม่มีข้อมูลจะเริ่มว่างเปล่า: เพิ่มกระเป๋าและหมวดหมู่เองได้ หรือใช้ "กู้คืนจากไฟล์สำรอง"

## สถานะการทดสอบ (โปรดอ่าน)
- ฝั่ง Supabase ทดสอบแล้ว: ตาราง/RLS (ผู้ใช้อื่นมองไม่เห็นข้อมูล เขียนข้ามบัญชีไม่ได้), upsert, ข้อมูลที่นำเข้าตรงกับไฟล์สำรอง (ยอดรวมตรง)
- โค้ดแอปเขียนโดยไม่ได้คอมไพล์หรือรันบนอุปกรณ์จริง (สภาพแวดล้อมที่สร้างไม่มี Gradle/Android SDK และไม่มีเน็ตฝั่งเครื่องมือ)
  จึงยังไม่ได้ยืนยัน: การคอมไพล์, การเข้าสู่ระบบ/ซิงก์จริงบนมือถือ, การอัปโหลดรูปใบเสร็จ
  หากมี error ตอน Build ให้ส่ง Log มาแก้ได้

## ไอคอนหมวดหมู่และการจัดลำดับ
- ไอคอนอยู่ใน `app/src/main/assets/icons/<กลุ่ม>/` (16 กลุ่มตามโฟลเดอร์ในไฟล์ icon.zip) เลือกได้ตอนเพิ่ม/แก้ไขหมวดหมู่ (ยังเลือกอีโมจิแบบเดิมได้)
- ค่าไอคอนเก็บในคอลัมน์ `emoji` เป็นข้อความ `icon:<กลุ่ม>/<ชื่อ>`
- หน้าเพิ่มรายการ: กดค้างที่หมวดหมู่แล้วลากเพื่อจัดลำดับ (บันทึกที่คอลัมน์ `sort_order`)
- **ต้องรัน `supabase/migration_category_sort_order.sql` ใน Supabase SQL Editor หนึ่งครั้งก่อนใช้เวอร์ชันนี้**
