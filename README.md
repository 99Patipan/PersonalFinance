# สมุดรายรับ-รายจ่าย (PersonalFinance)

แอป Android (Kotlin + Jetpack Compose + Material 3) เก็บข้อมูลบน **Supabase** (Postgres + Storage) ของตัวเอง ต้องล็อกอินและต้องใช้อินเทอร์เน็ตเพื่อดู/บันทึกข้อมูล ไม่มีโฆษณา

## ฟีเจอร์
- Dashboard: ยอดรวม กระเป๋า สรุปเดือน ปฏิทินรายวัน ธุรกรรมล่าสุด กราฟ สัดส่วนหมวด งบประมาณ
- เพิ่ม/แก้ไข/ลบ/ดูรายละเอียด/ค้นหา/กรองรายการ แนบรูปใบเสร็จ
- หลายกระเป๋าเงิน โอนระหว่างกระเป๋า (ไม่นับเป็นรายรับ/รายจ่ายรวม)
- หมวดหมู่: เพิ่ม/แก้ไข/ลบได้ เลือกไอคอนรูปภาพ 1,380 แบบ (16 กลุ่ม) หรืออีโมจิ
- หน้าเพิ่มรายการ: กดค้างที่หมวดหมู่แล้วลากเพื่อจัดลำดับ (ใช้ลำดับนี้ทุกหน้า)
- รายงานรายเดือน/รายปี เปรียบเทียบเดือนก่อน ค่าเฉลี่ยต่อวัน หมวดที่ใช้มากสุด
- งบประมาณรายเดือนตามหมวด พร้อมแจ้งเตือนเมื่อใกล้เกิน (ตั้งได้ 70/80/90%)
- ส่งออก CSV, สำรอง/กู้คืน JSON (รวมรูปใบเสร็จ)

## การเชื่อมต่อ Supabase
- URL และ publishable key อยู่ใน `app/src/main/java/com/patipan/finance/data/SupabaseConfig.kt`
  ถ้าเข้าสู่ระบบไม่ได้ ให้เปลี่ยน `API_KEY` เป็น legacy anon key (Settings > API Keys)
- สร้างฐานข้อมูลใหม่: รัน `supabase/schema.sql` ใน SQL Editor (สร้างตาราง นโยบาย RLS และ bucket รูปใบเสร็จครบ)
- ถ้าใช้ฐานข้อมูลที่สร้างจากเวอร์ชันเก่า (ยังไม่มีคอลัมน์ `sort_order`) ให้รัน `supabase/migration_category_sort_order.sql` หนึ่งครั้ง
- ตาราง: `wallets`, `categories`, `transactions`, `budgets` ทุกแถวมี `user_id` และเปิด RLS ให้เห็น/แก้ได้เฉพาะเจ้าของ
- รูปใบเสร็จเก็บใน Storage bucket `receipts` (ส่วนตัว) path แบบ `<userId>/<uuid>.jpg`
- เข้าสู่ระบบด้วยอีเมล + รหัสผ่านของบัญชีที่สร้างไว้ใน Authentication > Users
- แผนฟรีของ Supabase จะพักโปรเจกต์ถ้าไม่มีการใช้งานนาน 1 สัปดาห์ (ข้อมูลไม่หาย กดกู้คืนที่ Dashboard ได้) แนะนำให้สำรอง JSON เป็นระยะ
