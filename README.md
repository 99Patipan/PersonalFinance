# สมุดรายรับ-รายจ่าย (PersonalFinance)

แอป Android (Kotlin + Jetpack Compose + Material 3 + Room + DataStore) ใช้งานออฟไลน์ ไม่มีโฆษณา ไม่ต้องล็อกอิน ไม่มี permission อินเทอร์เน็ต

## วิธีที่ 1: Build APK ด้วย GitHub Actions (ไม่ต้องลง Android Studio)
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github` ที่เป็นโฟลเดอร์ซ่อน) ที่ branch `main`
3. ไปที่แท็บ **Actions** > **Build APK** (รันเองเมื่อ push หรือกด **Run workflow**)
4. เมื่อเสร็จ เปิดการรันนั้น เลื่อนลงไปที่ **Artifacts** แล้วดาวน์โหลด `PersonalFinance-apk` (ข้างในคือ `PersonalFinance.apk`)
5. ถ้า Build ไม่ผ่าน ดู Log ในขั้นตอนที่ขึ้นสีแดง และ Artifact ชื่อ `build-logs`

## วิธีที่ 2: Build ใน Android Studio
เปิดโฟลเดอร์นี้ด้วย Android Studio (Koala ขึ้นไป, JDK 17) รอ Gradle Sync แล้วกด Run หรือ Build > Build APK(s)
ไฟล์จะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

> หมายเหตุ: `gradle-wrapper.jar` (ไฟล์ไบนารี) ไม่ได้รวมมาด้วย Workflow ใช้ Gradle 8.9 ผ่าน `gradle/actions/setup-gradle` จึงไม่ต้องใช้ไฟล์นี้
> ถ้าต้องการใช้ `./gradlew` ให้รัน `gradle wrapper --gradle-version 8.9` หนึ่งครั้ง (Android Studio สร้างให้อัตโนมัติ)

## ติดตั้งบนมือถือ
คัดลอก APK ไปที่เครื่อง เปิดไฟล์ แล้วอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" (Android 8.0 ขึ้นไป)

## ฟีเจอร์
- Dashboard: ยอดรวม กระเป๋า สรุปเดือน ปฏิทินรายวัน ธุรกรรมล่าสุด กราฟ สัดส่วนหมวด งบประมาณ บันทึกของฉัน
- เพิ่ม/แก้ไข/ลบ (มีหน้าต่างยืนยัน)/ดูรายละเอียด/ค้นหา/กรอง รายการ, ทศนิยม 2 ตำแหน่ง, แนบรูปใบเสร็จ
- หลายกระเป๋าเงิน โอนระหว่างกระเป๋า (ไม่นับเป็นรายรับ/รายจ่ายรวม) ยอดคงเหลือคำนวณจากรายการจริงเสมอ
- หมวดหมู่เริ่มต้น เพิ่ม/แก้ไข/ลบได้
- รายงานรายเดือน/รายปี เปรียบเทียบเดือนก่อน ค่าเฉลี่ยต่อวัน หมวดที่ใช้มากสุด
- งบประมาณรายเดือนตามหมวด พร้อมแจ้งเตือนเมื่อใกล้เกิน (ตั้งได้ 70/80/90%)
- ส่งออก CSV, สำรอง/กู้คืน JSON (รวมรูปใบเสร็จ) ผ่าน Storage Access Framework

## ข้อมูลเริ่มต้น
แอปสร้างกระเป๋า "เงินสด" ยอดเริ่มต้น 0 และหมวดหมู่เริ่มต้นเท่านั้น ไม่มีรายการเงินตัวอย่าง

## สถานะการทดสอบ (โปรดอ่าน)
โค้ดนี้เขียนโดยไม่ได้คอมไพล์หรือรันบนอุปกรณ์จริง (สภาพแวดล้อมที่สร้างไม่มี Gradle/Android SDK และไม่มีเน็ต)
จึงยังไม่ได้ยืนยัน: การคอมไพล์, การทำงานบนมือถือ, การคงอยู่ของข้อมูลหลังรีสตาร์ต
หากมี error ตอน Build ให้ส่ง Log มาแก้ได้
