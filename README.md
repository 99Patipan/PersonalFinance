# สมุดรายรับ-รายจ่าย (PersonalFinance)

แอป Android (Kotlin + Jetpack Compose + Material 3) เก็บข้อมูลบน **Supabase** (Postgres + Storage) ของตัวเอง ต้องล็อกอินและต้องใช้อินเทอร์เน็ตเพื่อดู/บันทึกข้อมูล ไม่มีโฆษณา

## ฟีเจอร์
- Dashboard: ยอดรวม กระเป๋า สรุปเดือน ปฏิทินรายวัน ธุรกรรมล่าสุด กราฟ สัดส่วนหมวด งบประมาณ
- เพิ่ม/แก้ไข/ลบ/ดูรายละเอียด/ค้นหา/กรองรายการ แนบรูปใบเสร็จ
- หลายกระเป๋าเงิน โอนระหว่างกระเป๋า (ไม่นับเป็นรายรับ/รายจ่ายรวม)
- หมวดหมู่: เพิ่ม/แก้ไข/ลบได้ เลือกไอคอนรูปภาพ 1,380 แบบ (16 กลุ่ม) หรืออีโมจิ
- หน้าเพิ่มรายการ: กดค้างที่หมวดหมู่แล้วลากเพื่อจัดลำดับ (ใช้ลำดับนี้ทุกหน้า)
- รายงานรายเดือน/รายปี เปรียบเทียบเดือนก่อน ค่าเฉลี่ยต่อวัน หมวดที่ใช้มากสุด
- งบประมาณรายเดือนตามหมวด พร้อมแจ้งเตือนเมื่อใกล้เกิน (ตั้งได้ 70/80/90%)
- ส่งออก CSV, สำรอง/กู้คืน JSON (รวมรูปใบเสร็จ)
